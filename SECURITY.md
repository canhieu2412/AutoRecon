# Security Policy

Auto Recon is intended for authorized labs, CTFs, internal security testing,
and systems where you have explicit permission to perform reconnaissance.

Do not use this project against third-party systems without authorization.

## Reporting Security Issues

If you find a vulnerability in Auto Recon itself, please open a private report
or contact the maintainer through GitHub.

When reporting, include:

- affected version or commit
- steps to reproduce
- impact
- suggested fix if available

Do not include real third-party credentials, tokens, private target data, or
scan outputs from systems you are not allowed to share.
